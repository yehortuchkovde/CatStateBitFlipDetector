# Alice & Bob challenge helpers

The MIT notice in [LICENSE](LICENSE) applies to the Alice & Bob code in this
folder: `models.py`, `simulate.py`, `rates.py`, `protocol.py`, `records.py`, and
`scoring.py`. These six files are copied unchanged from the challenge repository.
The local `__init__.py` is a reduced package initializer.

Source: <https://aqora.io/Alice_Bob/catch-the-flip>, commit
`63f4db7c09e793f03f65a2610102d2ef5dbca1f532deb6cf44edaadd741def4c`.

The upstream MIT terms require retaining their copyright and permission notice
when redistributing this code. This is why this folder has its own license;
the repository's root license credits the new project code instead.
The detector and analysis in `../catflip/` are original project code, not part
of these upstream helpers. Dataset licensing is documented in `../../data/`.
